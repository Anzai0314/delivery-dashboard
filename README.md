# 配達記録 Web版 v1.1.0（PC・Android共有対応）

PCとAndroidで同じFirebaseデータを共有するため、匿名アカウントをメール／パスワードの共有アカウントへ昇格できる版です。

## 先に確認すること

- 今まで使っていたWeb版のデータは削除しません。
- 移行は旧コレクションから `users/{uid}` へのコピーです。
- 移行先に同じ文書がある場合は上書きしません。
- 自宅座標と自動稼働設定はクラウド同期せず、各端末で設定します。

## 移行手順

1. Firebase Consoleを開きます。
2. Authentication → Sign-in method で「メール/パスワード」を有効にします。
3. このフォルダの `index.html` を、今までのWeb版と同じサイトへ配置します。
4. 今までWeb版を使っていたPC・ブラウザでサイトを開きます。
5. 右上の同期表示を押します。
6. 自分のメールアドレスと6文字以上のパスワードを入力します。
7. 「このPCのデータを残してアカウント作成」を押します。
8. 「既存データを移行しました」または「既存データはそのままです」と表示されたことを確認します。
9. Firebase Consoleで `firestore.rules` を反映します。
10. Android版を開き、右上の同期表示から「既存アカウントでログイン」を選びます。

## 「旧Web版領域を権限不足で確認できません」と表示された場合

1. Firebase Consoleで `firestore-migration.rules` を一時的に反映します。
2. Web版右上の同期表示を開きます。
3. 「旧Web版データをもう一度確認・移行」を押します。
4. 移行完了後、すぐに `firestore.rules` を反映して旧領域へのアクセスを閉じます。

`firestore-migration.rules` は移行中だけ使用してください。旧データは読み取り専用で、移行処理が削除・更新することはありません。

## 今後の使い方

- PCとAndroidの両方で同じメールアドレスとパスワードを使います。
- 売上、件数、稼働時間、走行距離、経費、目標、休日、税金設定、食事記録が共有されます。
- パスワードを忘れないよう安全な場所へ保管してください。
